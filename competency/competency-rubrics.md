# Engine 3 · C0–C5 可观察评分标准

| 等级 | 可观察行为 | 反例（不得升级） |
|---|---|---|
| C0 | 无法说出该能力涉及的任务 | — |
| C1 | 能用自己的话解释相关概念与流程 | 只会背诵术语 |
| C2 | 在提示下完成标准任务并说明每步依据 | 全程照抄步骤、无法解释 |
| C3 | 独立选择方法、完成标准任务、结果可复现 | 答案对但过程不可复现 |
| C4 | 遇到异常能定位原因、调整方案并验证 | 只在标准条件下成功 |
| C5 | 迁移到新场景、比较方案优劣、提出改进或新方法 | 换个参数就失败 |

评分维度（每项 0–2）：结果正确性、推理过程、方法合理性、独立完成度、异常处理、约束满足、可解释性。总分不是唯一判据：**独立完成度与异常处理任一为 0 时，不得判 C4 及以上**。

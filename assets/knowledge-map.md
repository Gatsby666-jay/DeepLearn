# 知识结构图模板

双花括号 `{{...}}` 为待填字段，属于模板变量，填充后删除本行说明。

## 使用说明

- 只表达「包含」关系：每个节点**只有一个父节点**。
- 首次输出只到 L2；用户选中分支后再展开 L3–L6。
- 节点 ID 三图共用，保持稳定。
- 不要在此图画「必须先于」的边。

```markdown
假设：{{缺失项采用的默认假设}}

## 分类
主类：{{A–G}} ｜ 辅类：{{最多两个}} ｜ 置信度：{{高/中/低}}
依据：{{引用用户原话关键词}}

## 知识结构图（L0–L2）
```

```mermaid
flowchart TD
  {{L0_ID}}["{{学习目标}}"] --> {{L1A_ID}}["{{领域 A}}"]
  {{L0_ID}} --> {{L1B_ID}}["{{领域 B}}"]
  {{L1A_ID}} --> {{L2A1_ID}}["{{模块 A1}}"]
  {{L1B_ID}} --> {{L2B1_ID}}["{{模块 B1}}"]
```

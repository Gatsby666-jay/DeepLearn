# 知识依赖图模板

双花括号 `{{...}}` 为待填字段，属于模板变量，填充后删除本行说明。

## 使用说明

- 边语义：`A --> B` = **先掌握 A，才能学 B**。
- 允许多父、允许跨分支边；主动按 three-graphs.md 的「跨分支边发现清单」逐条提问。
- 输出后必须运行 `scripts/validate_map.py` 校验无环，并把校验结果写进本节。
- 有环时先破环（拆成「先会用 → 后懂原理」），再重新校验，不允许带环生成路线图。

```markdown
## 知识依赖图
```

```mermaid

  {{前置ID}}["{{前置概念}}"] --> {{节点ID}}["{{当前概念}}"]
  {{另一分支前置ID}}["{{另一分支前置}}"] --> {{节点ID}}
  {{节点ID}} --> {{后继ID}}["{{后继概念}}"]
```

# 学习路线图模板

双花括号 `{{...}}` 为待填字段，属于模板变量，填充后删除本行说明。

## 使用说明

- 顺序来自依赖图拓扑排序，不来自教材章节，也不来自结构图的父子关系。
- 默认推荐 B 高效路径；同时给出 A / C 的取舍说明，不强制最长路径。
- 阶段时长写区间，并注明估算所依据的每周投入假设。

```markdown
## 推荐路径：{{A 入门 / B 高效 / C 深研}}（理由：{{一句}}）

| 阶段 | 节点 | 依赖阶段 | 阶段产出 / 检验点 | 时长 |
|---|---|---|---|---|
| S1 | {{ID 列表}} | — | {{完成后能做什么}} | {{3–5h}} |
| S2 | {{ID 列表}} | S1 | {{完成后能做什么}} | {{4–6h}} |

关键路径：{{S1 → S2 → …}}
可跳过项：{{○/△ 节点及跳过代价}}
并行支线插入点：{{阶段编号或「无」}}

其它路径取舍：
- A 入门：{{相对推荐路径增加了什么}}
- C 深研：{{相对推荐路径增加了什么}}

假设：{{每周可用时长等}}
下一步：① 从 S1 开始上第一课 ② 换成 A / C 路径 ③ 先诊断前置缺口
```

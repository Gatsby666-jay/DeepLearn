# 概念分析模板（第一性原理，按需选取）

双花括号 `{{...}}` 为待填字段。只保留本次需要的项，不机械输出全部 13 项。

```markdown
## {{概念名}}（节点 {{ID}}，分类 {{A–G}}）

1. 定义：{{一句无循环定义的表述}}
2. 动机：{{它解决什么问题；没有它时会怎样}}
3. 直觉：{{一个具体画面或类比}} —— 标注：这是简化类比，严格表述是 {{…}}，类比在 {{…}} 处失效
4. 构成：{{必要组件 + 各自作用}}
5. 机制：{{按因果/时间顺序的逐步链条，不跳步}}
6. 第一性原理：{{定律 / 性质 / 假设，注明适用范围}}
7. 推导：{{逐步推导，每步注明依据}}
8. 依赖：{{前置节点 ID 列表}}
9. 关联：{{与 X 的关系 / 与 Y 的易混点}}
10. 应用：{{至少一个真实场景}}
11. 局限：{{具体条件 + 失效表现 + 替代方案}}
12. 验证：{{实验 / 计算 / 仿真 / 实现}} —— 做什么、观察什么、什么结果算支持
13. 延伸：{{1–2 个方向，不展开教学}}

## 练习
- 基础理解：{{题目 + 完成判据}}
- 概念推理 / 推导：{{题目 + 完成判据}}

## 迁移（L3 之后）
- 跨域同构：{{…}}
- 对象变化 / 远域连接 / 反事实：{{按需至少一类}}

## 反向教学（L5 之前）
起点只给：{{L5/L6 原理}}
请依次重建：机制 → 行为 → 形式化表达 → 解释原问题

下一步：① 提交作答 ② 换更简单的一版 ③ 展开某个前置节点
```

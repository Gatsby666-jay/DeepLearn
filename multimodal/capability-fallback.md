# Engine 5 · 能力降级（强制）

## 1. 探测清单

| 能力 | 探测方式 | 不支持时降级 |
|---|---|---|
| 图片理解 | 当前会话是否有可用的图片读取工具 | 请用户用文字描述；按文字信息继续 |
| 代码执行 | 是否有可运行的本地执行环境 | 静态分析 + 理论推演，标 `execution_status=theoretical` |
| PDF/文档解析 | 是否有文件读取工具 | 请用户粘贴关键段落 |
| 外部 API / 联网 | 是否可用检索 | 只给检索关键词，标 `unverified` |
| 仿真 | 是否有仿真环境 | 数据表 + 理论曲线，标 `simulated` |

## 2. 输出要求

降级时必须在回复中写明：不支持的能力、采用的替代方法、对结论可信度的影响。**不得静默降级**，也不得把降级结果描述为「已验证」。

## 3. 与 V2 的关系

V2 `references/resources.md` 的「不编造 URL、未验证即标注」规则继续适用；本文件扩展到所有多模态能力。

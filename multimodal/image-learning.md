# Engine 5 · 图片学习工作流

## 1. 允许的图片类型

电路图、数学题、结构图、实验照片、代码截图、机械结构图。

## 2. 五步

1. 识别图片中的信息（元件/符号/公式/结构/代码）。
2. 提取相关知识点，映射到现有 `NODE-*`；无对应节点时只提出新增建议，不自动建图。
3. 找出可能的知识缺口（对照 `prerequisites`）。
4. 生成针对性教学与实验任务（实验需标 `execution_status`）。
5. 必要时要求补充更清晰的图片或局部裁剪。

## 3. 禁止

- 不臆造图中看不清的数值、标签或连线。
- 不把「看起来像」当成确认识别；低置信写 `extraction_confidence=low`。
- 不支持图片输入时，**必须在回复中明确说明**并给文本替代方案（让用户用文字描述电路连接/公式/结构）。

# Engine 6 · 学习效果评估

## 1. 跟踪项

前测/后测差异、延迟测试表现、独立解题、迁移任务、项目完成、重复错误、提示依赖程度。

## 2. 五种层次必须区分

短期记忆 / 理解 / 应用 / 迁移 / 长期保持。对应判据：

| 层次 | 判据 |
|---|---|
| 短期记忆 | 即时回忆通过，延迟测试未做 |
| 理解 | 能解释机制与反例 |
| 应用 | 独立完成常规任务 |
| 迁移 | 变更条件/跨领域通过 |
| 长期保持 | 延迟复习通过且 confidence=strong |

## 3. 不得

- 不用「模型觉得讲得好」判定成功。
- 不把即时正确率等同于长期保持。
- 不用无依据的精确数字伪装科学测量；缺失数据写 `null`。

# 学习路径生成引擎

生成或调整路线图时载入。

## 输入

依赖图（已通过 `scripts/validate_map.py` 校验，无环）+ 每个节点的属性：

| 属性 | 取值 | 用途 |
|---|---|---|
| `prerequisites[]` | 节点 ID 列表 | 拓扑排序依据 |
| `difficulty` | 1–5 | 阶段内排序、路径取舍 |
| `importance` | 必 / 选 / 拓 | 路径取舍 |
| `time_estimate` | 小时区间 | 阶段时长 |
| `practical_value` | 高 / 中 / 低 | 高效路径的优先级 |
| `mastery` | 0–5 | 跳过已达标的节点 |

## 生成步骤

1. 从依赖图取拓扑序（可用 `validate_map.py` 输出的 `order` 与 `stages`）。
2. 同层内按「难度低 → 高」「必 → 选 → 拓」排；概念型节点排在操作型之前。
3. 每 3–6 个节点合并为一个阶段；每阶段写「完成后能做什么」与一个检验点。
4. 阶段时长为各节点区间之和，用区间表示，不给精确天数。
5. 标出关键路径（依赖链最长的一条）与可跳过项。
6. 生成 A / B / C 三条视角，默认推荐 B。

## 三条路径

| 路径 | 面向 | 取舍规则 |
|---|---|---|
| A 入门 | 零基础、要系统学 | 保留全部「必」节点，补充常识级前置，节奏更细、阶段更小 |
| B 高效（默认） | 多数用户 | 保留关键路径上的「必」节点 + 实践价值高的节点；「选 / 拓」标为可稍后补；理论细节标为「用到再查」 |
| C 深研 | 要原理、机制、研究向 | 在 A 基础上补 L5/L6 原理、推导、局限与延伸节点，并接入反向教学与迁移任务 |

不把所有用户塞进最长路径；不因为用户说「想学好」就默认给 C。切换路径时保留已完成的节点与掌握度，只增删节点。

## 阶段表格式

| 阶段 | 节点 | 依赖阶段 | 阶段产出 / 检验点 | 时长 |
|---|---|---|---|---|
| S1 | … | — | … | 3–5h |

阶段编号在路径切换时保持稳定，便于 state 记录进度。

## 硬约束

- 不以教材章节顺序替代依赖顺序。
- 不在依赖图有环时输出路线图。
- 不把结构图的父子关系当作阶段顺序。
- 不把「必 / 选 / 拓」混为一谈：只有「必」进入关键路径。
- 不跳过前置；若用户要求跳过，标注跳过的代价与后续可能卡住的位置。
- 时长为估算区间，标注「按每周 3–5 小时估算」等假设。

## 与失败处理衔接

目标与时间冲突时（如「三天精通 X」）：不劝退、不缩目标，输出「最小可达子集」—— 取关键路径上最前面的 1–2 个阶段作为可达目标，并明确列出未覆盖范围。

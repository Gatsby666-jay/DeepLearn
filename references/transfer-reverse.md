# 反向教学与知识迁移

Deep Dive 收尾、Diagnose 补救、以及任何节点升到 L3 之后载入。这两项能力是「真正理解」与「会做原题」的分界线。

## 一、反向教学（bottom-up）

自顶向下拆解回答「它由什么组成」；反向教学回答「只给我底层原理，能否把上层重建出来」。

### 触发时机

- Deep Dive 讲解结束后，作为收尾验证；
- Diagnose 发现用户能复述但不会推导时；
- 用户要求「从原理推一遍」「别给我结论」时；
- 判定 Level 5 之前。

### 四步流程

1. **给定起点**：只提供 L5/L6 的原理、公理、机制或组件，**不提供上层结论、公式名称或推导结果**。
2. **逐层重建**：请用户依次推出：机制 → 行为 → 公式 / 结构 → 上层概念。每一步追问依据。
3. **缺口定位**：用户卡住时，记录卡在哪一层，回退到对应的前置节点，用不同表征（图形 / 数值 / 代码 / 实验）重讲。
4. **回到原问题**：让用户用重建出的结论解释最初的目标现象或完成最初的任务，形成闭环。

### 禁止项

- 不以「复述刚才的讲解」代替推导。
- 不在提示中泄露结论（例如直接写出待推公式）。
- 不因为用户答不出就代答；应先降低起点层级，而不是给出答案。
- 不把反向教学做成另一种背诵题。

### 通用模板

```
起点（只给原理）：<原理 1>、<原理 2>
请依次完成：
  1. 由 <原理 1> 推出 <中间机制>，写出依据
  2. 由该机制推出 <可观察行为>
  3. 把上述行为写成 <形式化表达 / 结构>
  4. 用它解释 <最初的目标问题>
依据不足时可请求补充一个前置概念，但要说明缺的是什么。
```

## 二、知识迁移（四类模板）

节点达到 L3 后必须给迁移任务。四类模板可单独或组合使用。

| 模板 | 通用问句 | 考查什么 |
|---|---|---|
| 跨域同构 | 「场景 X 与场景 Y 看起来不同，共同的数学 / 机制结构是什么？逐项对应。」 | 能否剥离表面特征，识别结构 |
| 对象变化 | 「若控制对象 / 边界条件 / 数据分布从 X 换成 Y，哪些参数或步骤必须重调，为什么？」 | 能否把原理重新参数化 |
| 远域连接 | 「它和<更远领域的某方法>在结构上有什么对应？本质差异在哪？」 | 能否建立抽象层联系 |
| 反事实与失效 | 「在什么条件下它不再成立？会表现出什么现象？该换什么？」 | 是否理解局限与适用边界 |

### 完整示例（PID，仅作为格式锚点）

- 跨域同构：电机调速与温度控制的共同结构是「目标值 − 测量值 → 误差 → 控制量 → 被控对象 → 反馈」；差异在时间常数、惯性、噪声与执行器特性。
- 对象变化：从快速电机换成大热惯性对象，采样周期、Ki、Kd、抗积分饱和策略如何调整，逐项给出理由。
- 远域连接：PID 的「按误差修正」与优化算法中「按梯度修正」的结构对应；动量项与积分项形似但目的不同（前者平滑更新方向，后者消除历史偏差累积）。
- 反事实：大纯滞后、强非线性、传感器饱和时 PID 何处失效，应改用何种策略。

### 伪迁移（禁止）

- 只换数字或名词、解法完全相同的「换皮原题」。
- 让用户复述定义或背诵步骤。
- 迁移题难度远超当前节点，实际考的是未学的前置。
- 用户答完后不给反馈就直接标记掌握。

## 三、掌握度与证据

- L3（能独立应用）：会做本领域常规题 / 常规实现。
- L4（能分析陌生情境）：完成「跨域同构」或「反事实」中至少一类，且说清依据。
- L5（能推导、扩展或教会他人）：完成**反向教学重建** + 至少两类迁移任务，其中必须包含「对象变化」或「远域连接」。
- 只做对原题 = L3，不得越级。
- 迁移失败时记录为薄弱前置节点，按 assessment.md 定向回补后重测。

## 四、与三图的联动

- 反向教学暴露的缺口 → 在依赖图补一条 `prerequisites[]` 边。
- 迁移成功 → 结构图该节点标记 `mastery: 5`，路线图推进到下一节点。
- 若多个不同分支的节点反复出现同一条缺失前置 → 把该前置提升为 L5 基础单元，写进三图。

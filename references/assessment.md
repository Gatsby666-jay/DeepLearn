# 练习与掌握度引擎

每次教学结束、进入 Diagnose 模式、或需要判定掌握度时载入。

## 七类练习

| 类型 | 通用模板 | 主要对应层级 |
|---|---|---|
| 基础理解 | 「用自己的话说明 X，并指出一个它不成立的场合」 | L1→L2 |
| 概念推理 | 「若改变条件 C，结论会怎样变化？给出依据链」 | L2→L4 |
| 计算 / 推导 | 「从原理 P 出发独立推出结论 Q，不跳步」 | L2→L5 |
| 实现 | 「写出能跑通的最小实现，并给出可观察输出」 | L2→L3 |
| 调试 | 「给定故障现象与输出，定位原因并验证修复」 | L3→L4 |
| 真实应用 | 「把 X 用到一个未讲过的真实场景中」 | L3→L4 |
| 迁移 | 按 transfer-reverse.md 的四类模板出题 | L4→L5 |

题目必须绑定当前节点；不使用超出已学前置的题目。每题写清「完成判据」，避免「谈谈你的理解」这类无法判定的问法。

## 掌握度量表

| 级别 | 含义 | 可接受的证据 |
|---|---|---|
| 0 | 未学 | 无 |
| 1 | 认得概念 | 能从选项中辨认、说出名称 |
| 2 | 能解释 | 不看材料讲清定义与机制，指出一个反例 |
| 3 | 能独立应用 | 独立完成本领域常规题 / 常规实现 |
| 4 | 能分析陌生情境 | 完成跨域同构或反事实类任务，且说清依据 |
| 5 | 能推导、扩展或教会他人 | 完成反向教学重建 + 至少两类迁移任务（含对象变化或远域连接） |

## 证据规则（硬约束）

- **读了解释不升级**。只有用户的作答、推理过程或实践产出可以作为证据。
- 不因为「讲解很完整」而标记掌握。
- 不越级：只做对原题最高记 L3。
- 升级时写明依据（引用用户作答中的具体要点），不写「表现良好」。
- 用户自述「我懂了」只作为线索，不作为证据；需用一道短题确认。
- 证据不足时保持原级别，并给一个最小补测题。

## Diagnose 流程

1. 选 3–5 道覆盖关键前置的诊断题，从 L5 基础单元往上逐层测。
2. 记录每道题对应的节点 ID 与结果。
3. 找出**最早的失败节点**（而不是所有答错的题），它通常是真正的薄弱前置。
4. 输出缺口清单：节点 ID、缺失内容、影响的后继节点。
5. 定向回补：只重讲该节点及其必要前置，用不同表征。
6. 换题重测，不重复使用原题。
7. 更新依赖图（补遗漏的 `prerequisites[]`）与 state 的薄弱点字段。

## 薄弱点回补

- 回补任务必须是一个可独立完成的最小单元，25–45 分钟内可做完。
- 回补后必须重测，通过才允许继续原路线。
- 若同一前置在三个以上不同分支反复成为障碍，把它提升为 L5 基础单元，并在三图中显式标出。

## 动态闭环（G5，见 quality-gates.md）

诊断不是终点，必须触发路径调整：

1. 定位**最早的失败节点**（不是所有答错的题）。
2. 定向回补该节点及其必要前置，换一种表征。
3. **换题重测**，不重复使用原题。
4. 重排路线图：插入复习节点、后移受影响后继、必要时局部下调路径深度。
5. 更新三图版本号与 state：证据摘要、薄弱点、新的下一推荐任务。
6. 输出新的「下一步」，不直接进入原计划的下一节点。

触发重排的事件：掌握度变化、发现薄弱前置、补依赖边、破环、用户追加约束、切换 Mode。路线图不是一次生成后固定不变的；未重排就继续下一节点视为门禁失败。


## V2 增补：十类评估、证据与冲突

评估类型（canonical 枚举见 `core/data-schema.md`）：recall / explanation / application / derivation / debugging / prediction / counterexample / reverse_teaching / cross_domain_transfer / changed_condition_transfer。

每次掌握度变更写一条 `evidence`：`node_id, assessment_type, result, reasoning_quality, error_type, date, mastery_decision, confidence`。`confidence`（unassessed / provisional / supported / strong）与 `mastery_level` **不同轴**；置信度低于 supported 不得触发升级。

**冲突证据**：常规题通过但迁移任务失败时，两条证据都保留，不得用后者覆盖前者；不得判 L4/L5；定位缺失的迁移能力，设计针对性练习并触发路线重排。只做对原题最高记 L3。

延迟重评：按 `last_assessed`、错误频率、难度与遗忘风险安排，见 `learning/spaced-review.md`；重评写新 evidence，不改历史记录。
